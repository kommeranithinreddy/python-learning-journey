# Python itertools Module – Practice

This folder contains practice exercises based on Python's built-in
`itertools` module.

The exercises focus on creating iterators and working efficiently with
sequences and combinations of data.

## Exercises

### 1. chain
**File:** `chain.py`

Practice combining multiple iterables into a single iterator.

**Concepts:**
- `itertools.chain`
- Combining iterables
- Iterators

---

### 2. combinations
**File:** `combinations.py`

Practice generating combinations of elements from an iterable.

**Concepts:**
- `itertools.combinations`
- Selecting elements without repetition
- Combinations

---

### 3. count
**File:** `count.py`

Practice generating an infinite sequence of evenly spaced values.

**Concepts:**
- `itertools.count`
- Infinite iterators
- Starting values
- Step values

---

### 4. cycle
**File:** `cycle.py`

Practice repeatedly cycling through the elements of an iterable.

**Concepts:**
- `itertools.cycle`
- Infinite iteration
- Repeating sequences

---

### 5. islice
**File:** `islice.py`

Practice taking selected portions of an iterator without converting the
entire iterator into a list.

**Concepts:**
- `itertools.islice`
- Slicing iterators
- Start, stop, and step

---

### 6. permutations
**File:** `permutations.py`

Practice generating different possible arrangements of elements.

**Concepts:**
- `itertools.permutations`
- Ordering elements
- Permutations

---

### 7. product
**File:** `product.py`

Practice generating the Cartesian product of multiple iterables.

**Concepts:**
- `itertools.product`
- Cartesian product
- Combining multiple sequences

---

### 8. repeat
**File:** `repeat.py`

Practice repeatedly returning the same value.

**Concepts:**
- `itertools.repeat`
- Repeated values
- Controlling the number of repetitions

---

## Concepts Practiced

- `chain()`
- `combinations()`
- `count()`
- `cycle()`
- `islice()`
- `permutations()`
- `product()`
- `repeat()`
- Iterators
- Infinite iterators
- Combinations and permutations
- Cartesian products
- Efficient iteration

## Purpose

These exercises were completed to build practical familiarity with Python's
`itertools` module and understand how iterators can be used to efficiently
work with sequences and generate combinations of data.
