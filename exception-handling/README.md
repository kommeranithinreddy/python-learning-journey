# Python Exception Handling Practice

This folder contains my practice programs for Python Exception Handling. The goal of these exercises is to understand how to write reliable programs by handling errors gracefully instead of allowing the program to crash.

## Topics Covered

- `try` and `except`
- Multiple `except` blocks
- `else` and `finally`
- Raising exceptions using `raise`
- Creating custom exceptions
- Handling multiple custom exceptions
- Input validation
- Business rule validation
- Exception handling in OOP programs

## Practice Programs

| File | Description |
|------|-------------|
| `zero_division_error.py` | Handle `ZeroDivisionError` during division. |
| `value_error.py` | Handle invalid integer input (`ValueError`). |
| `index_error.py` | Handle list index out of range errors. |
| `key_error.py` | Handle missing dictionary keys. |
| `catching_exception_details.py` | Display exception type and message. |
| `successful_division.py` | Demonstrates `try`, `except`, `else`, and `finally`. |
| `login_validation.py` | Validate user login using exception handling. |
| `age_validation.py` | Use `raise` for age validation. |
| `salary_validation.py` | Validate salary using `raise`. |
| `bank_withdrawal.py` | Validate bank withdrawal amount using `raise`. |
| `invalid_age_error.py` | Custom exception for invalid age. |
| `insufficient_balance_error.py` | Custom exception for insufficient balance. |
| `multiple_custom_exceptions.py` | Handle multiple custom exceptions in one program. |
| `invalid_roll_number_error.py` | Validate student roll number using a custom exception and OOP. |

## Key Learning Outcomes

- Prevent program crashes using exception handling.
- Validate user input effectively.
- Raise meaningful exceptions for business rules.
- Create and use custom exception classes.
- Write cleaner and more maintainable Python programs.
