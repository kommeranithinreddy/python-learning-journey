# Python pathlib Module – Practice

This folder contains practice exercises based on Python's built-in
`pathlib` module.

The exercises focus on creating, checking, navigating, and working with
files and directories using object-oriented path handling.

## Exercises

### 1. Building Path
**File:** `building_path.py`

Practice building file and directory paths using `Path`.

**Concepts:**
- `pathlib.Path`
- Creating paths
- Path construction

---

### 2. Checking on My System
**File:** `checking_on_my_system.py`

**Concepts:**
- `Path`
- Filesystem paths
- System-specific paths

## Concepts Practiced

- `pathlib.Path`

- Path inspection

## Purpose

These exercises were completed to build practical familiarity with Python's
`pathlib` module and learn a modern, object-oriented approach to working with
file and directory paths.
