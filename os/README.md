# Python os Module – Practice

This folder contains practice exercises based on Python's built-in `os`
module.

The exercises focus on working with directories, environment variables,
and operating-system related functionality.

## Exercises

### 1. Checking API Key Existence
**File:** `checking_api_key_existence.py`

Practice checking whether an API key exists in the environment variables.

**Concepts:**
- `os.environ`
- Environment variables
- Checking whether a variable exists
- Basic handling of sensitive configuration

---

### 2. Creating Directory Chain
**File:** `creating_directory_chain.py`

Practice creating a directory structure using Python.

**Concepts:**
- `os.makedirs()`
- Creating nested directories
- Working with directory paths

---

### 3. Getting Environment Username
**File:** `getting_env_username.py`

Practice retrieving the current username from environment variables.

**Concepts:**
- `os.environ`
- Environment variables
- Accessing operating-system information

---

### 4. Working with Directory
**File:** `working_with_directory.py`

Practice working with directories using the `os` module.

**Concepts:**
- `os` module
- Directory operations
- Current working directory
- Creating and working with directories

---

## Concepts Practiced

- `os` module
- Environment variables
- `os.environ`
- Directory operations
- `os.makedirs()`
- Working with the current directory
- Creating nested directories
- Accessing operating-system information

## Related Practice

The `os.path` folder contains separate exercises focused specifically on
working with file and directory paths.

## Purpose

These exercises were completed to build practical familiarity with Python's
`os` module and understand how Python can interact with the operating system.
