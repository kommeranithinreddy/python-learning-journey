# Python os.path – Practice

This folder contains practice exercises based on Python's `os.path`
functionality.

The exercises focus on working with file and directory paths and checking
path-related information.

## Exercises

### 1. Checking File Extension
**File:** `checking_extension.py`

Practice checking and working with file extensions using path information.

**Concepts:**
- File extensions
- `os.path`
- Working with file paths

---

### 2. Checking os.path
**File:** `checking_os_path.py`

Practice checking and working with paths using functions provided by
`os.path`.

**Concepts:**
- `os.path`
- Path checking
- File and directory paths

---

### 3. Path Exercise
**File:** `path_exercise.py`

Practice performing common operations on file and directory paths.

**Concepts:**
- `os.path`
- File paths
- Directory paths
- Path manipulation

---

## Concepts Practiced

- `os.path`
- File paths
- Directory paths
- File extensions
- Path checking
- Path manipulation

## Relationship with `os`

The `os.path` folder is kept separately because these exercises focus
specifically on handling and working with paths.

## Purpose

These exercises were completed to build practical familiarity with Python's
`os.path` functionality and understand how to work with file and directory
paths.
