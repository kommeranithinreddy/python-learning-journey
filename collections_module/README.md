# Python Collections Module – Practice

This folder contains practice exercises based on Python's built-in
`collections` module.

The exercises focus on useful collection types and techniques that are
commonly used when working with structured data.

## Exercises

### 1. Counter Class Exercise
**File:** `counter_class_exercise.py`

Practice using `Counter` to count occurrences of elements in a collection.

**Concepts:**
- `collections.Counter`
- Counting elements
- Accessing frequency counts

---

### 2. defaultdict Using int
**File:** `default_dict_using_int.py`

Practice using `defaultdict` with `int` as the default factory.

**Concepts:**
- `collections.defaultdict`
- Default values
- Using `int` as a default factory
- Automatic counting

---

### 3. defaultdict Using list
**File:** `default_dict_using_list.py`

Practice using `defaultdict` with `list` to automatically create lists for
missing keys.

**Concepts:**
- `defaultdict`
- Using `list` as a default factory
- Grouping values by keys

---

### 4. deque maxlen and pop
**File:** `deque_maxlen_and_pop.py`

Practice using `deque` for efficient insertion and removal of elements.

**Concepts:**
- `collections.deque`
- `maxlen`
- `append()`
- `pop()`
- Working with a fixed-size collection

---

### 5. Named Tuple
**File:** `named_tuple.py`

Practice creating structured, tuple-like objects using `namedtuple`.

**Concepts:**
- `collections.namedtuple`
- Named fields
- Accessing values using field names
- Immutable structured data

---

### 6. Transaction Check Using Counter
**File:** `transaction_check_using_counter.py`

Practice using `Counter` to analyze and compare transaction-related data.

**Concepts:**
- `Counter`
- Frequency analysis
- Comparing collections
- Applying collections to a practical problem

---

## Concepts Practiced

- `Counter`
- `defaultdict`
- `deque`
- `namedtuple`
- Counting and grouping data
- Working with structured collections
- Practical use of Python's `collections` module

## Purpose

These exercises were completed to build practical familiarity with Python's
`collections` module and understand how its specialized data structures can
simplify common programming tasks.
