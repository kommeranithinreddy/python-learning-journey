# Python File Handling – Practice

This folder contains practice exercises for working with files in Python.

The exercises cover reading and writing text files, working with CSV files,
and handling JSON data.

## Exercises

### 1. Book JSON Writer
**File:** `book_json_writer.py`

Practice writing book-related data to a JSON file.

**Concepts:**
- JSON files
- Writing JSON data
- `json` module
