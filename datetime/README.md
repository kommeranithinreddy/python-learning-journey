# Python datetime Module – Practice

This folder contains practice exercises based on Python's built-in
`datetime` module.

The exercises focus on creating, formatting, converting, comparing, and
calculating dates and times.

## Exercises

### 1. Birthday Object
**File:** `birthday_object.py`

Practice creating and working with a date object for a birthday.

**Concepts:**
- `date`
- Creating date objects
- Accessing date information

---

### 2. Calculating Time
**File:** `calculating_time.py`

Practice calculating differences between dates and times.

**Concepts:**
- Date/time arithmetic
- Time differences
- `datetime` calculations

---

### 3. datetime Formatting
**File:** `datetime_formatting.py`

Practice formatting date and time objects into readable formats.

**Concepts:**
- `strftime()`
- Format codes
- Custom date/time formats

---

### 4. datetime Object
**File:** `datetime_object.py`

Practice creating and working with `datetime` objects.

**Concepts:**
- `datetime`
- Date and time components
- Accessing year, month, day, hour, minute, and second

---

### 5. datetime to String
**File:** `datetime_to_string.py`

Practice converting a `datetime` object into a formatted string.

**Concepts:**
- `strftime()`
- Datetime-to-string conversion
- Formatting date and time

---

### 6. Deadline Calculate
**File:** `deadline_calculate.py`

Practice calculating deadlines by performing date and time arithmetic.

**Concepts:**
- `datetime`
- `timedelta`
- Adding and subtracting time
- Date calculations

---

### 7. String to datetime
**File:** `str_to_datetime.py`

Practice converting a date/time string into a `datetime` object.

**Concepts:**
- `strptime()`
- String-to-datetime conversion
- Parsing date/time strings

---

### 8. timedelta Object
**File:** `timedelta_object.py`

Practice using `timedelta` to represent and calculate differences in time.

**Concepts:**
- `timedelta`
- Adding time
- Subtracting time
- Time duration calculations

---

### 9. Timezones
**File:** `timezones.py`

Practice working with timezone-aware date and time objects.

**Concepts:**
- Timezones
- Timezone-aware `datetime` objects
- Working with different time zones

---

### 10. Working with Time
**File:** `working_with_time.py`

Practice creating and working with time objects.

**Concepts:**
- `time`
- Hours, minutes, seconds, and microseconds
- Accessing time components

---

## Concepts Practiced

- `datetime`
- `date`
- `time`
- `timedelta`
- `strftime()`
- `strptime()`
- Date and time arithmetic
- Date/time formatting
- String ↔ datetime conversion
- Timezones

## Purpose

These exercises were completed to build practical familiarity with Python's
`datetime` module and learn how to work with dates and times in real-world
programming tasks.
